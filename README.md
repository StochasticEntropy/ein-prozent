# Ein Prozent – das Denk-Quiz

Ein Browser-Spiel im Stil des Formats „Das 1% Quiz“: 19 Fragen von der 90 %- bis zur 1 %-Frage,
gegen 99 simulierte Mitspieler, moderiert von Comic-Duos. Alle Fragen sind eigene Fragen.

Spielen: die GitHub-Pages-Seite dieses Repositorys öffnen. Auf iPhone/iPad in Safari „Teilen → Zum Home-Bildschirm“,
auf Android in Chrome „App installieren“ – danach läuft es auch offline.
